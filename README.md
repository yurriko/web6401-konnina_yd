# Лабораторная работа №2

## Инɸᴏᴩʍᴀция

**Тема:** HTML и CSS. Многостраничный сайт о закусках и развлечениях к Новому году

**Расположение:** папка `lab2/`, точка входа – `lab2/index.html`

### Ꮯᴛᴩуᴋᴛуᴩᴀ

- `index.html` – главная страница
- `snacks.html` – таблица закусок для праздничного стола
- `olivier.html` – состав и порядок приготовления оливье
- `activities.html` – идеи для вечера
- `about.html` – данные об авторе
- `css/style.css` – единый файл стилей, включая анимацию гирлянды
- `images/` – логотип в svg и картинки

### Ꮲᴇᴀᴧиɜᴏʙᴀнныᴇ ᴛᴩᴇбᴏʙᴀния

- Страниц: 5
- HTML: блочные (`div`, `p`, `ul`, `table`, `figure`) и строчные (`a`, `strong`, `small`) элементы, ссылки, изображения, таблицы
- CSS: отдельный подключаемый файл; селекторы типа, класса, идентификатора, потомка, атрибута, псевдокласса
- Цвет: праздничная палитра на CSS-переменных
- Мигающая гирлянда: анимация `@keyframes` без JavaScript
- Таблицы: выравнивание по левому краю, по центру, по правому краю
- JavaScript, Bootstrap и иные библиотеки не используются
