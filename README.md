# Лабораторная работа №2

## Инɸᴏᴩʍᴀция

**Тема:** HTML и CSS. Многостраничный сайт о художественных материалах для рисования

**Расположение:** папка `lab2/`, точка входа – `lab2/index.html`

### Ꮯᴛᴩуᴋᴛуᴩᴀ

- `index.html` – главная страница, шкала твёрдости, схема карандаша
- `pencils.html` – таблица маркировки карандашей
- `markers.html` – типы маркеров, порядок работы, цифровые аналоги
- `about.html` – данные об авторе
- `css/style.css` – единый файл стилей
- `images/` – логотип и схема карандаша в формате SVG

### Ꮲᴇᴀᴧиɜᴏʙᴀнныᴇ ᴛᴩᴇбᴏʙᴀния

- Страниц: 4
- HTML: блочные (`div`, `p`, `ul`, `table`, `figure`) и строчные (`a`, `strong`, `abbr`, `code`) элементы, ссылки, изображения, таблица
- CSS: отдельный подключаемый файл; селекторы типа, класса, идентификатора, потомка, атрибута, псевдокласса
- Цвет: палитра на CSS-переменных
- Таблица: выравнивание по левому краю, по центру, по правому краю
- JavaScript, Bootstrap и иные библиотеки не используются
