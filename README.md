# Лабораторная работа №2

## Инɸᴏᴩʍᴀция

**Тема:** HTML и CSS. Многостраничный сайт о закусках и развлечениях к Новому году

**Расположение:** папка `lab2/`, точка входа – `lab2/index.html`

### Ꮯᴛᴩуᴋᴛуᴩᴀ

- `index.html` – главная страница
- `snacks.html` – таблица закусок для праздничного стола
- `olivier.html` – состав и порядок приготовления оливье
- `activities.html` – идеи для вечера
- `about.html` – данные об авторе
- `css/style.css` – единый файл стилей, включая анимацию гирлянды
- `images/` – логотип в svg и картинки

### Ꮲᴇᴀᴧиɜᴏʙᴀнныᴇ ᴛᴩᴇбᴏʙᴀния

- Страниц: 5
- HTML: блочные (`div`, `p`, `ul`, `table`, `figure`) и строчные (`a`, `strong`, `small`) элементы, ссылки, изображения, таблицы
- CSS: отдельный подключаемый файл; селекторы типа, класса, идентификатора, потомка, атрибута, псевдокласса
- Цвет: праздничная палитра на CSS-переменных
- Мигающая гирлянда: анимация `@keyframes` без JavaScript
- Таблицы: выравнивание по левому краю, по центру, по правому краю
- JavaScript, Bootstrap и иные библиотеки не используются

# Лабораторная работа №3

**Тема:** основы JavaScript. Набор функций в проекте `js-tasks` (каркас: [teach-kirshdv/js-tasks](https://github.com/teach-kirshdv/js-tasks)).

**Расположение:** папка `lab3/`, реализация – `lab3/src/core.js`, тесты – `lab3/src/core.spec.js`.

### Ꮲᴇᴀᴧиɜᴏʙᴀнныᴇ ɸунᴋции

| Функция | Описание | Приём |
|---|---|---|
| `isInteger(n)` | проверка целого числа | побитовое ИЛИ `(n \| 0) === n` |
| `even()` | чётные числа от 2 до 20 | цикл с шагом 2 |
| `sumTo(n)` | сумма чисел от 1 до n | цикл |
| `recSumTo(n)` | сумма чисел от 1 до n | рекурсия |
| `factorial(n)` | факториал | цикл |
| `isBinary(n)` | проверка степени двойки | `n > 0 && (n & (n - 1)) === 0` |
| `fibonacci(n)` | n-е число Фибоначчи | цикл, деструктуризация |
| `getOperationFn(initialValue, operatorFn)` | функция с накопляемым значением | замыкание |
| `sequence(start, step)` | генератор арифметической прогрессии | замыкание, параметры по умолчанию |
| `deepEqual(a, b)` | глубокое сравнение значений | рекурсия по свойствам |
