# Лабораторная работа №4

**Тема:** Современный CSS и основы объектно-ориентированного программирования на JavaScript. Модернизация многостраничного сайта о закусках и развлечениях к Новому году.

**Расположение:** папка `lab4/`, точка входа — `lab4/index.html`.

### Структура

- `index.html` — главная страница с использованием Flexbox
- `snacks.html` — таблица праздничных закусок
- `olivier.html` — рецепт и порядок приготовления оливье
- `activities.html` — идеи для новогоднего вечера с использованием CSS Grid
- `about.html` — информация об авторе
- `form.html` — форма новогодней анкеты гостя
- `css/style.css` — общий файл стилей, CSS-переменные и анимация
- `js/form.js` — обработка формы и JavaScript-класс `GuestRegistration`
- `images/` — изображения и SVG-логотип

### Реализованные требования

- **Flexbox:** используется для построения макета главной страницы и навигации.
- **Grid:** используется для размещения карточек на странице развлечений.
- **CSS-переменные:** цвета сайта задаются через переменные в `:root`.
- **CSS-анимация:** реализована мигающая новогодняя гирлянда с помощью `@keyframes`.
- **HTML-форма:** содержит текстовое поле, email, числовое поле, выпадающий список, текстовую область и checkbox.
- **ООП JavaScript:** реализован класс `GuestRegistration` с конструктором и методом `print()` для форматированного вывода информации в консоль.
- **Обработка формы:** при отправке создаётся объект класса с введёнными данными, вызывается метод `print()`, отображается сообщение об обработке анкеты и очищаются поля формы.
- **JavaScript:** для обработки события `submit` используется `addEventListener()`, стандартная отправка формы отменяется через `event.preventDefault()`.

### Запуск

Открыть файл `lab4/index.html` в браузере или запустить сайт через Live Server в VS Code.

Для проверки работы JavaScript перейти на страницу `form.html`, открыть консоль разработчика (F12), заполнить форму и нажать кнопку отправки.

Дополнительные библиотеки не используются.
